# Domain Specification: eternalia.reader.relations

## 対象
| Ref | Aspect |
| --- | --- |
| eternalia.reader | 複数実行間の関係・実DOM構造・状態不変性（適用する規則に限定） |

## 規則
| ID | 条件 | 要求 | 検証 |
| --- | --- | --- | --- |
| reader.order.relation | 同一言語の公開語集合・スペルが同じでマスタ順/手動順だけが異なる二つの実行 | どちらの単語表示列もスペル昇順。スペルが異なる語の相対順はマスタ順/手動順の変更によって反転しない。照合順等の未決部分は固定しない。 | 実API/DOMで複数語と異なるマスタ順・手動順を比較 |
| reader.ui.structure | 公開設定詳細・言語詳細・章詳細のDOMとナビゲーション | 本文・文法リンク・章一覧リンクは実際の公開対象IDと結び付く。未公開本文やリンクは表示しない。 | DOM/アクセシビリティ・リンク遷移・匿名HTTPの対象ID照合 |
| reader.pos.rename | 同じ安定品詞IDの下書き名称変更前後と明示公開後 | 公開前は公開マスタの旧名称、明示公開後は同じIDの新公開名称。下書き名称は漏れない。 | 同一単語IDの公開表示と公開マスタの複数実行照合 |
| reader.words.relation | 言語閲覧、検索、品詞絞込 | Wを匿名APIから取得した同一公開言語Lの全公開語、qを検索語、cを選択公開品詞名とする。各語wの公開品詞名集合N(w)は公開意味の安定品詞IDをLの公開マスタへ対応させて得られる非空名称の集合。表示ID集合はWのうち採用済みスペル/意味検索条件に適合し、cがなしまたはc∈N(w)である全語と一致する。品詞選択肢は検索前のWのN(w)の和集合、検索と品詞をANDで適用する。表示列はそのID・公開スペルの重複なし射影でスペル昇順。異なるスペルの相対順を作者手動順や品詞順で反転させない。検索の追加対象・照合方式・同綴タイブレークは採用済み範囲を超えて固定しない。 | 実公開資料集合、公開マスタ、複合条件から独立に対象集合と順序を比較。欠落/余剰/異系列/非公開・同名別ID・名称変更前後を対照 |
| reader.settings.relation | カテゴリ閲覧、設定検索、タグ絞込、並び | 選択カテゴリの公開Tipのうち名称または公開設定項目が検索条件に適合し、指定公開タグ名があればその公開タグを持つものだけを表示する。選択肢は検索前の当該カテゴリの公開Tipの公開タグ名の集合。非公開項目は検索条件判定にも漏えいさせない。名称順選択時は表示対象の実名称順、既定順・公開更新順は現行の選択肢として区別し、その未採用細部は固定しない。検索語とタグ条件の一方の変更で他方を解除しない。 | 公開/非公開設定と項目、タグ名、検索語と実DOM列・検索結果を照合 |
| reader.pos.label | 公開単語詳細の意味品詞 | 各表示意味IDについて、単語の所属言語の公開マスタ内で同一安定品詞IDを持つ項目が存在する場合のみその公開nameを表示する。不在・未指定はラベルなしとし、同名の別ID・別言語・下書き名称を代用しない。 | 実意味ID・公開マスタIDとDOMラベル、未指定/別ID/非公開マスタ対照 |
| reader.chapter.relation | 正規公開章の章一覧導線と、遷移先の章一覧閲覧（直接URLも含む） | 正規公開章の表示時の系列ID s と保持公開版上の所属部ID p は状態.選択シリーズ・状態.所属部と同一である。リンク操作の遷移要求はこの(s,p)を保持し、その公開祖先列から生成された正規URLを指す。章一覧の読込み成功時は入力された(s,p)が実公開部に対応し、表示対象ID=p、章ID集合は同一部pに所属する実効公開章の全件と一致し、採用された章順を保持する。遷移先で部が非公開・不在・系列や祖先不整合なら表示結果を返さず対象拒否とする。リンク操作時の状態で遷移先の公開可否を代用しない。下書き親・別部・別系列・適合ラベルを代用しない。 | 実章の公開親ID、リンク先ID、遷移後URL/章ID列を前後比較。直接URL、非公開化後、別系列の対照 |
| reader.route.scope | 言語・カテゴリ・章一覧・詳細への正規アクセス完了時 | 取得された匿名公開ツリーは入力系列の公開版上の正規親鎖を持つ資料だけで構成される。入力された系列・種別・対象IDおよび固定論理階層上の中間祖先IDを、対象から公開親参照を辿って得られる実IDと照合する。階層は200 §6の採用済み論理構造を用いる。系列→編→部→章、系列→言語→語/文法、系列→カテゴリ→設定→設定項目等の各レベルを区別し、該当しない中間祖先をなしとする。対象種別に対応する正規親鎖が構成できない場合、公開根系列IDをなしとする。余分な階層・循環・不在親を捨てて一致させず、要求された祖先IDや要求種別を観測値へ転記しない。各観測ID/種別は同じ取得済み公開資料と親参照の実データに由来し、詳細応答ID/種別は同じ匿名詳細応答に由来する。詳細では匿名詳細応答のID・種別も同一でなければならない。取得失敗は対応する取得値なしとして拒否側に入る。正規のURL表現との一致は領域別の導線検証で確認し、特定ルーター関数を規定しない。成功には当該実ID、公開内容・リンクのみを使用する。不在・不整合・非公開・取得失敗で非公開内容を表示しない。URL文字列の比較を外部から与えられる適合真偽値で代用しない。 | 匿名HTTPのツリーと詳細・ブラウザの実URL・DOMを照合。別系列、別親、非公開化、公開時刻、直接URLを対照 |

自由文の規則・観測関係は正式な機械証明済みではない。単一実行の操作・状態変化はTCEに置き、検証方法は規範Interfaceにしない。
