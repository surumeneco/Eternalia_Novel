網羅要求: partial

## 振る舞い

メニューの開閉、背景操作可否、フォーカス先の領域を実際に観測できる仕様値として表す。閉じている際の一般的なキー操作、広幅の通常ナビゲーション、および他の画面の状態更新はこの境界のEffectとして強制しない。フォーカス対象の同一性・循環順は領域別規則 shell.focus.position / shell.focus.initial / shell.focus.cycle / shell.focus.restore も同時に満たす必要がある。表示パネルはモバイルオーバーレイのみを表す。

## 残る検証境界

機械式は開閉とフォーカス領域の状態関係を保持する。領域内の個別対象IDの正確な移動、初期フォーカスの選択、起点の実在/可視性、実際の背景遮断、表示寸法はDomainSpecの規則であり、その未証明は残る。有限の観測分類はDOMの実位置から独立に観測するもので、期待する遷移先・テスト合否を入力として用いない。Draftの形式的合格を正式な仕様確定や実装適合としない。
