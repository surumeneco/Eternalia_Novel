# CAT Draft — AC-24/27: 複数シリーズの章本文分離と匿名公開境界

Status: Draft (not Confirmed)
Source: forGPT/Creating/Projects/Websites/Eternalia_Novel/10_要件定義/100_機能仕様.md (SR-01〜04、PB-10〜12), 40_開発・検証/400_受入検証計画.md (AC-24/27)
Scope: 2シリーズに同名の編・部・章を作成し、異なる本文と公開状態を匿名読者に分離して提供する。

## Process / invariants

- 同名の章が異なるシリーズにあっても、ID・所属親子関係・本文は混在しない。
- 両シリーズ公開時は各シリーズの公開ツリーと章の直URLがそれぞれ自身の公開版本文を返す。
- 一方のシリーズを非公開にしても他方のシリーズは公開を維持し、非公開シリーズ配下の章は匿名ツリー・直URLから取得できない。
- 章本文の下書き更新は別Workで検証し、本Workはシリーズ分離と匿名公開境界に限定する。

## Candidate exploratory vectors

| Case | Input | Expected |
| --- | --- | --- |
| V1 | A/Bに同名の編・部・章を登録し、異なる本文で公開 | 各シリーズツリーと直URLが固有ID・本文を返す |
| V2 | シリーズBのみ非公開 | Bツリー/章は匿名404、Aは引き続き200 |
| V3 | Aの公開章をブラウザで開く | Aの本文のみ表示されBの本文は混入しない |

本Draftは正式CAT Gateや生成テストのpassを意味しない。合成作者セッションと匿名実ブラウザの探索的検証である。
