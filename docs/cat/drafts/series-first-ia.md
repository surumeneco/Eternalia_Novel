# シリーズ起点の画面責務とナビゲーション（Draft）

## 根拠と権限

採用済みのSR-01〜04、WR-01/08、旧v0.3のホーム/読者/管理ルート、新着へのジャンプ、現行200・220のシリーズ起点の画面設計および利用者の受入指摘（Issue #165）。既存の公開制御・作者認可・下書き保存・明示公開版更新・新規作成の深いリンクは維持する。本書はAI作成のDraftであり無断でConfirmedに昇格しない。既存文書にない画面仕様は提案として扱う。

## 画面とデータの境界

| 表示階層 | 主責務 | 対象 |
| --- | --- | --- |
| サイトホーム | 公開シリーズを発見・選択する。新着導線には所属シリーズが分かること | 公開シリーズと公開済み新着 |
| シリーズトップ | 選択済みシリーズの情報と4領域の入口を示す | 選択したシリーズのみ |
| シリーズ内4領域 | 既存の領域固有ページで編・部・章／カテゴリ・設定／言語・辞書／年代区分・出来事を表示 | 選択したシリーズのみ |
| 作者の編集入口 | 作業するシリーズを選び、領域を選択し、選択対象を編集する | 作者本人が扱う当該シリーズ |
| 公開管理 | 公開版更新・自分の公開設定と祖先による実効状態・日時を管理する | 選択したシリーズの対象 |
| メモ | 作者用メモを管理する | 既存仕様に従い独立操作 |

## 観測可能な規則

| ID | Condition | Expected |
| --- | --- | --- |
| IA-01 | 匿名閲覧者がホームを開く | 公開シリーズが主要導線で、未選択状態のストーリー・設定集・辞書・年表を独立した並列コンテンツとして列挙しない |
| IA-02 | シリーズ詳細を開く | 4領域への入口を分ける。個別ノードの統合フラット一覧を主コンテンツにしない |
| IA-03 | ヘッダー/共通サイドバーを使う | シリーズ選択前は4領域を独立リソースとしてナビゲートしない。選択後は当該シリーズへのリンクとなる |
| IA-04 | ホームの新着を辿る | 既存の新着ジャンプを維持しつつ、所属シリーズが分かる表示とシリーズへ戻れる文脈を持つ |
| IA-05 | 作者が編集入口を開く | 認証済みであっても無条件で全シリーズの全ドメインのツリーを同列に展開せず、シリーズを選択してから対象領域を選ぶ |
| IA-06 | 作者が既存の `?item=`、`?create=...&parent=...` でアクセス | 正当なシリーズ選択を復元し、参照元の編集対象/作成対象を維持。未保存内容の保護とサーバ側の所属・権限検証を維持 |
| IA-07 | 公開設定を変更する | 編集とは独立した公開管理導線を使用し、シリーズ・自身の公開状態・祖先による実効状態を区別する |
| IA-08 | 固定UI文言が日英切替される | `作者の書斎` の不採用名称を撤回し、本文・ユーザー作成テキストを翻訳しない |
| IA-09 | 画面を変更した場合 | 旧v0.3・旧FEの色・役割トークン・共通骨格、匿名公開とDiscord作者認可は維持する |

## 保留事項

- 現行200で未決のURL最終形式、作者用編集領域の厳密な視覚サイズや6分類機械的依存許可表を、本Workだけで確定しない。
- メモがシリーズに所属するという新要件を導入しない。
- 既存の公開一覧旧URLは直接URLで到達できる互換のシリーズ選択入口として残す案を検証する。
- CATのProcess Closure、Model Conformance、TDD Queue、Red/Green、実機受入はそれぞれ未実行/未確認であり、本Draftはこれらの代替にならない。
